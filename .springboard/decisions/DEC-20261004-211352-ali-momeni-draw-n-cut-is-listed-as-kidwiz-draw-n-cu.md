## Context

Every other Kidwiz app is listed on the App Store as "Kidwiz - <App>". Draw'n'Cut 1.0 shipped as plain "Draw'n'Cut", so a search for Kidwiz did not show it beside the others.

## Decision

Ali, 2026-10-04: the store name is "Kidwiz - Draw'n'Cut". It ships with version 1.0.1 (build 57), the same app under the new name. The name under the icon on the home screen stays "Draw'n'Cut".

## Consequences

The rename takes effect when Apple approves 1.0.1, which releases automatically.
